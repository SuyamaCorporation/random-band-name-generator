# Random Band Name & Album Art Generator

## 概要
ランダムなバンド名・アルバムタイトル・ジャンルを生成し、Canvasでジャンル別の抽象的なアルバムカバーを描画するクリエイティブツール。

## 機能
- バンド名・アルバムタイトル・ジャンル・年のランダム生成
- ジャンル別アルバムカバーart生成（メタル=ダーク幾何学/アンビエント=グラデーション/その他=カラフルブロック）
- 生成したバンドの保存リスト（最大10件）

## 使い方
「Generate Band」ボタンを押すたびに新しいバンドとアルバムカバーが生成されます。気に入ったバンドは「Save to List」で保存できます。
